Stationen

Integration

So verbindet sich das POS-System mit dem Küchen-Display

Server-Adresse

Diese URL muss vom POS-System erreichbar sein (gleiches Netzwerk).
http://localhost:3000

API-Endpunkte

POST
/api/orders
Neue Bestellung anlegen → erscheint sofort auf dem Küchen-Display
GET
/api/orders
Alle aktiven Bestellungen abrufen
GET
/api/orders/history
Abgeschlossene Bestellungen abrufen (max. 24h)
PATCH
/api/orders/:id/status
Status einer Bestellung ändern: new | in_progress | ready | completed
DELETE
/api/orders/:id
Bestellung als abgeschlossen markieren und von allen Displays entfernen
GET
/api/settings
Aktuelle Konfiguration (Stationen, Schwellenwerte etc.) abrufen
Beispiel: Bestellung anlegen
POST /api/orders HTTP/1.1 Content-Type: application/json { "order_number": "42", "table_number": "7", "server_name": "Anna", "notes": "Nussallergie!", "items": [ { "name": "Wiener Schnitzel", "quantity": 2, "modifiers": ["ohne Zitrone"], "station": "grill" }, { "name": "Cola", "quantity": 2, "station": "bar" } ] }
